# 三行少年自动化写作 Agent — 研究与设计依据 V1.0

> 更新日期：2026-09-21  
> 本文说明为什么 V1.0 采用“真实成长纪实 × 户外生命力 × 专业克制”的内容策略，以及哪些结论来自三行少年项目资料、哪些来自外部研究/规则。

# 1. 项目资料给出的核心传播逻辑

三行少年的项目资料已经给出一个非常清晰的商业与内容底层：

- 项目不是“儿童骑行培训”，而是“城市儿童户外运动成长课堂”。
- 家长最终购买的不是自行车或一次周末活动，而是孩子可持续、可被看见的成长。
- 产品应该长期围绕每周课程、月度挑战、季度赛事/成长日、假期营和成长档案构建。
- 内容增长飞轮来自真实课程：参加活动 → 产生高光 → 记录照片/视频 → 家长愿意分享 → 新家庭进入。
- 品牌故事的正确顺序是“先用真实故事打动人，再用科学与方法建立信任”。
- 项目从创业第一天就应该持续记录磨课、体验课、迭代、失败和改进，而不是等一切包装完美后才开始传播。

因此，Agent 不应采用传统教育机构的“课程卖点堆砌 + 强促销”作为主风格，而应把孩子、教练和真实场景放在前面。

# 2. 为什么选择“真实成长纪实”

儿童户外课天然拥有强视觉和强故事素材：

- 动作前后变化；
- 技能学习；
- 自主处理问题；
- 队友互动；
- 教练现场判断；
- 环境变化；
- 失败后再尝试。

这些素材本身就比抽象的“培养自信、锻炼意志、提升综合素质”更有说服力。

因此 Agent 的核心规则是：

> 抽象成长结论必须尽量回到行为证据。

例如，不直接写“孩子变勇敢了”，而是写用户明确提供的事实：“第一轮在坡前停了三次，第四轮自己重新排队又试了一次。”

如果没有真实证据，则不写成长结论。

# 3. 为什么强调“户外生命力”

外部内容趋势和三行少年产品方向高度一致。

公开的 2025–2026 小红书母婴/户外行业资料显示，“自然养育”“户外探索”“高质量陪伴”“身体与心理韧性”等主题持续受到关注；公开行业材料还显示，小红书户外运动内容和搜索规模处于较高水平。

这意味着三行少年不应该只竞争“骑行课”这个词，而应该长期占领更大的心智：

- 城市孩子的真实户外生活；
- 周末高质量运动；
- 孩子身体与心理的真实成长；
- 家庭对“自然、运动、成长”的新需求。

注意：行业趋势只用于帮助确定内容方向，不能被包装成平台官方“流量保证”。

# 4. 为什么强调“专业克制”

儿童教育和运动内容很容易走向两个极端：

- 只讲情绪，不够专业；
- 堆脑科学、教育学、数据，反而失真。

三行少年品牌更适合第三种路径：

> 真实故事先建立兴趣，专业解释再建立信任，而且科学只说到证据允许的程度。

因此系统提示词明确禁止：
- “户外让海马体变大”；
- “竞争让学习效率提高 30%”；
- “骑行开发大脑”；
- “户外治疗近视”；
- 未经证据支持的医疗、心理或智力效果承诺。

可以谨慎表达：
- 自然环境暴露与儿童身体活动、心理健康和部分认知指标存在积极关联；
- 规律身体活动有益于体能和部分执行功能；
- 户外时间对近视发生的预防价值比“治疗近视”有更可靠依据。

# 5. 平台为什么必须原生重写

## 公众号
公众号更适合完整建立信任：
- 一个场景；
- 一次课程；
- 为什么这么设计；
- 教练怎么判断；
- 孩子真实发生了什么；
- 报名或下一场。

所以它承担“完整故事 + 品牌方法论”。

## 小红书
小红书同时具有发现和搜索属性。

三行少年内容要主动覆盖真实家长会搜索的表达：
- 重庆遛娃；
- 重庆亲子户外；
- 儿童骑行；
- 7–12 岁户外课；
- 周末带娃去哪；
- 儿童户外运动。

但关键词必须自然出现，不能堆词。

内容本身更像“真实体验/主理人记录/家长决策信息”，而不是机构新闻稿。

## 抖音
短视频首先是画面。

儿童户外项目最有优势的不是口播，而是：
- 转弯；
- 刹车；
- 障碍；
- 跑坡；
- 摔倒后重新来；
- 团队任务；
- 孩子真实原声；
- 教练一对一纠正。

因此规则是“一条视频一个观点”，而不是把整篇公众号压缩成 60 秒。

## 朋友圈
朋友圈最重要的是信任关系。

更适合：
- 机构清晰发布；
- 教练个人真实记录；
- 一件具体小事；
- 一个轻 CTA。

不适合假装第三方家长“自来水”。

# 6. 为什么取消原 Agent 的“强制选题确认”

原 auto-writing-agent 的 9 步公众号流程适合深度长文：先搜索、给选题、等用户确认、再写。

但三行少年高频运营的典型输入是：

> “这是明天活动海报，帮我发公众号、小红书、朋友圈。”

或：

> “这是今天拍的 20 张照片，帮我做活动回顾。”

如果每次都强制停下来选题，会破坏自动化价值。

所以 V1.0 改成：
- 资料足够 → 自动判断阶段与主传播点 → 直接成稿；
- 存在关键事实冲突、安全问题 → 才询问；
- 普通缺失 → 用 [待补充] 继续完成。

# 7. 为什么把未成年人风控做成硬闸门

依据中国《个人信息保护法》，不满十四周岁未成年人的个人信息属于敏感个人信息，处理此类信息应取得未成年人的父母或者其他监护人的同意并制定专门处理规则。

依据《广告法》，不得利用不满十周岁的未成年人作为广告代言人；针对不满十四周岁未成年人的商品或服务广告，也不得诱导其要求家长购买或包含可能引发不安全模仿的内容。

因此本 Agent 默认检查：
- 清晰儿童人脸是否有适用授权；
- 是否泄露学校、电话、住址、固定轨迹；
- 是否把儿童包装成购买号召主体；
- 是否出现不安全动作并被美化；
- 是否需要裁切、打码或换图。

# 8. 骑行传播为什么单独做道路年龄检查

中国《道路交通安全法实施条例》规定，在道路上驾驶自行车、三轮车必须年满 12 周岁，并规定不得在道路上学习驾驶非机动车。

三行少年早期客户包括大量 6–12 岁儿童，因此品牌传播应优先呈现：
- 封闭场地；
- 运动公园；
- 专门骑行区域；
- 其他合法、适龄的非社会道路训练场景。

具体活动仍应按当地场地和最新规定执行。

# 9. WorkBuddy 部署设计依据

WorkBuddy 官方 Skills 文档采用：
- 每个 Skill 独立目录；
- 必需 `SKILL.md`；
- 可选 `references/`、`scripts/`、`templates/`；
- `SKILL.md` 通过 YAML frontmatter 描述元数据；
- 可用 `@references/xxx.md` 等方式引用配套资料。

因此本项目没有只交付一个超长 Prompt，而是同时提供：

```
workbuddy-skill/
├── SKILL.md
├── references/
└── templates/
```

同时保留 `SYSTEM_PROMPT.md`，方便：
- WorkBuddy Buddy/Agent；
- Claude Project；
- OpenClaw；
- 其他支持系统提示词但不支持 Skills 的工具。

# 11. V1.0 需要通过什么验证

Agent 是否成功，不看它“写得像不像 AI”。

看五件事：

1. 同样一组素材，四个平台是否真的不同；
2. 用户只上传海报时，是否少问问题、直接干活；
3. 活动后是否能从照片中找到故事，但不越界编造；
4. 文案是否长期强化“真实成长”而不是只卖一次活动；
5. 连续使用 10–20 次后，用户是否只需要轻改，而不是每次大改。

V1.0 只是起点。

真正应该持续沉淀进 Agent 的，是每次活动后的：
- 高表现标题；
- 家长评论；
- 孩子真实语言；
- 教练现场判断；
- 报名疑问；
- 内容数据；
- 被用户删除和保留的句子。

这些才会逐渐形成三行少年的专属内容资产。
