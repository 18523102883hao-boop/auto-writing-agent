# 发布安全与合规闸门 V1.0

> 本文件是内容发布前的品牌风控清单，不替代律师意见或当地主管部门的正式要求。

# Gate 1：未成年人肖像与个人信息

三行少年内容大量涉及儿童。

发布前必须检查：

- 是否已取得适用的监护人拍摄/发布授权；
- 是否公开儿童全名；
- 是否泄露学校、班级、住址、电话、固定活动轨迹；
- 是否公开可识别的成长档案、健康/体测等敏感信息；
- 是否出现其他未授权儿童清晰人脸。

对于不满 14 周岁儿童的个人信息应更加谨慎。

不确定授权：
提示用户确认授权，或建议换成背影、远景、打码/裁切。

---

# Gate 2：儿童广告表达

避免让儿童扮演“产品代言人”。

不要写成：
- “我最喜欢三行少年，大家都来报名！”
- “妈妈快给我买这个课！”

不要诱导孩子向父母施压购买。

低龄儿童尤其不能被包装成广告代言主体。

可以真实记录：
- 孩子在课程中的自然原话；
- 现场体验；
- 真实行为；
前提是授权和语境合适。

---

# Gate 3：绝对化与虚假承诺

删除或改写：
- 最好
- 第一
- 顶级
- 100%
- 保证
- 一定
- 全重庆唯一
- 上完就能……
- X 节课彻底改变……

除非属于可客观证明、合法合规且有充分依据的事实，仍建议克制表达。

---

# Gate 4：医疗、近视、脑科学和成长功效

禁止：
- 治疗近视
- 提高智商
- 开发大脑
- 改善 ADHD
- 治疗焦虑
- 增强免疫力
- 保证长高
- 改善某疾病
等医疗/确定功效语言。

户外时间与近视：
只能谨慎说“与降低近视发生风险相关/对预防有价值”，不能说治疗已有近视。

研究结论：
相关性不能写成因果。

---

# Gate 5：户外运动风险

内容中如涉及：
- 骑行
- 攀爬
- 水上
- 越野
- 复杂地形
- 高强度挑战

检查：
- 场地是否合法/适龄；
- 装备和护具是否正确；
- 是否有专业看护；
- 是否把危险动作美化成勇敢；
- 是否会让其他儿童轻易模仿。

必要时加入：
“活动在教练组织及安全规则下进行，请勿自行模仿。”

但不要机械地每篇都塞免责声明。

---

# Gate 6：道路骑行

低龄儿童骑行传播尤其谨慎。

不要把未达到法定道路骑行年龄的儿童在普通社会道路骑行作为课程常态卖点。

优先呈现：
- 封闭场地
- 公园/运动场合法区域
- 专门骑行场
- 非社会道路训练环境

涉及具体法律年龄和场地规则时，正式发布前应按活动所在地的最新规定核验。

---

# Gate 7：隐私保护型文案

公开案例时优先：
- “一名 9 岁学员”而不是姓名；
- “这次课里一个孩子”；
- 模糊学校、住址等无关身份。

如果家长明确同意使用姓名，也不要披露与内容无关的个人信息。

---

# Gate 8：最后判断

发布前问五个问题：

1. 这句话是事实，还是为了好看加出来的？
2. 如果我是孩子家长，我会介意这样公开吗？
3. 这个画面是否可能诱发危险模仿？
4. 这项“成长效果”有证据吗？
5. 去掉夸张词后，内容还成立吗？

如果第五题答案是否定的，说明内容本身还不够真实，应回到素材，而不是继续加营销词。
