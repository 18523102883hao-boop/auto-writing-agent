# 三遍审校Checklist

本文件是文章审校的完整检查清单。每次审校按顺序执行三遍，每遍有不同的关注点。

---

## 第一遍：内容审校（逻辑、事实、结构）

### 事实核查
- [ ] 所有数据和数字是否准确？（面积、投资额、泳池参数、价格等）
- [ ] 时间节点是否正确？（成立时间、活动日期等）
- [ ] 产品名称、品牌名称是否正确？（28度活水馆、夫子医、彩虹泳帽等）
- [ ] 技术术语是否准确？（电磁脉冲、富氢、中药汤池等）
- [ ] 政策引用是否准确？（体教融合、健康中国、双减等）
- [ ] 所有案例是否真实？（不能编造会员故事）

### 逻辑检查
- [ ] 论点和论据是否一致？
- [ ] 前后是否有矛盾？
- [ ] 因果关系是否成立？
- [ ] 论证是否充分？（不是空泛的断言）

### 结构检查
- [ ] 是否有跑题的段落？
- [ ] 段落之间的过渡是否自然？
- [ ] 开头是否吸引人？
- [ ] 结尾是否有力？
- [ ] 整体结构是否层层递进？

### 引用检查
- [ ] 搜索结果引用是否准确？
- [ ] 来源是否标注？
- [ ] 是否有未验证的信息？（标注"待确认"）

---

## 第二遍：风格审校（AI味降重）⭐ 核心

### AI味检测
- [ ] 是否包含AI味词汇黑名单中的词语？（参见 `AI味词汇黑名单.md`）
- [ ] 是否有"不是...而是..."连续出现？
- [ ] 是否有排比句超过3组？
- [ ] 是否有转折词连续出现？（但是、然而、不过）
- [ ] 开头是否使用了AI式开头？（"在当今...的时代"）
- [ ] 结尾是否使用了AI式结尾？（"综上所述"、"总而言之"）

### 增加人味
- [ ] 抽象表达是否替换为具体数字/案例？
- [ ] 中立客观的描述是否替换为明确观点？
- [ ] 书面语是否改为口语化？
- [ ] 是否加入了适度的语气词？（确实、其实、说实话）
- [ ] 是否有个人视角和态度？
- [ ] 是否有真实细节？（具体场景、具体数字）

### 句式检查
- [ ] 是否有过于工整对称的句式？（AI倾向于整齐排列）
- [ ] 是否有"首先...其次...最后..."的机械结构？
- [ ] 句子长短是否有变化？（不全是长句或短句）
- [ ] 是否有活泼的短句穿插？

### 常见AI腔改写示例
| 改前（AI腔） | 改后（人味） |
|-------------|-----------|
| 在当今AI技术飞速发展的时代 | （直接删除，从具体事情开始） |
| 显著提升了效率 | 每个项目省了3-5小时 |
| 充分利用 | 用好 |
| 进行操作 | （直接用动词） |
| 不仅...而且... | （拆成两句话） |
| 在实际使用过程中 | 用下来 |
| 具有重要意义 | （说明具体意义） |
| 值得一提的是 | （直接说内容） |
| 毋庸置疑 | 确实 |

---

## 第三遍：细节打磨（标点、排版、节奏）

### 句子长度
- [ ] 主体句子是否在15-25字之间？
- [ ] 是否有超过30字的长句？（找出来拆短）
- [ ] 是否有适当的短句穿插？（3-10字的短句增加节奏感）

### 段落长度
- [ ] 每段是否在手机屏幕3-5行以内？
- [ ] 是否有过长的段落需要拆分？

### 标点符号
- [ ] 是否多用句号、少用逗号连接长句？
- [ ] 逗号是否超过3个才出现句号？（需要拆句）
- [ ] 感叹号使用是否适度？（不过多）
- [ ] 引号使用是否正确？

### 节奏感
- [ ] 是否有快慢结合？（短句→长句→短句交替）
- [ ] 是否有"金句"位置？（段落结尾的有力短句）
- [ ] 大声朗读是否通顺？

### 排版检查
- [ ] 小标题是否清晰？
- [ ] 是否有适当的空行分隔？
- [ ] 重点内容是否有加粗标注？
- [ ] 列表格式是否统一？

---

## 审校输出格式

每遍审校完成后，按以下格式输出：

### 第X遍审校结果

**修改总数**：X处

**关键修改**：
1. **修改1**
   - 位置：第X段
   - 原文：「...」
   - 改为：「...」
   - 原因：...

2. **修改2**
   - ...

**本遍总结**：（一句话总结这遍审校的核心改动）
