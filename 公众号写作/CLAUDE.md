# 公众号写作工作流程

本文件定义了公众号写作的完整 **9 步主流程**（Step 1-9）。进入本工作区后，按照以下流程执行。

> **步数口径（统一标准，勿改）**：主流程 = 9 步（理解需求 → 搜索 → 选题 → 协作文档 → 学风格 → 等数据 → 初稿 → 三遍审校 → 配图）。
> **封面 / 排版 / 发布 = 发布附录 A/B/C**，可选、可手动可自动化，**不计入 9 步**。开场白固定说"现在开始执行公众号写作流程，共9步"。

---

## Step 1: 理解需求 & 保存Brief

收到写作需求后：

1. **理解需求**：明确主题、目标读者、期望长度、核心信息
2. **保存Brief**：保存到 `_briefs/` 文件夹
   - 文件名格式：`项目名-brief.md`
   - 内容模板：

```
### Brief
- **主题**：
- **目标读者**：（家长/健身爱好者/健康养生人群/泳训家长/综合）
- **期望长度**：（1500-2000字 / 2000-3000字 / 3000字以上）
- **核心信息**：（这篇文章最重要的1-2个点）
- **特殊要求**：
- **截止时间**：
- **参考资料**：
```

3. **Think Aloud**：说明对需求的理解，确认是否有不清楚的地方

---

## Step 2: 信息搜索与知识管理 ⭐

**触发条件**：涉及新产品、新技术、新政策、新趋势、竞品信息时，此步骤必做。

### 自动化搜索（Tavily）

使用 **Tavily Search** 进行 AI 驱动的深度搜索：

```bash
# 基础搜索
node scripts/tavily-search.js --topic "青少年游泳训练" --reader "泳训家长"

# 深度搜索
node scripts/tavily-search.js --topic "AI在体育培训的应用" --depth advanced --max-results 8

# 多维度搜索
node scripts/tavily-search.js --topic "体教融合政策" \
  --queries "体教融合 2026" "游泳中考 重庆" "青少年体育培训 政策"
```

#### Tavily 搜索优势
- ✅ AI 生成摘要，快速理解核心信息
- ✅ 结果质量评分，优先高可信度来源
- ✅ 结构化输出，直接保存到知识库
- ✅ 免费额度：1000次/月

#### 搜索策略（按目标读者优化）

| 目标读者 | 搜索角度 |
|---------|---------|
| 家长 | `主题 + 家长关注/对孩子影响/教育意义` |
| 健身爱好者 | `主题 + 健身效果/训练方法/专业分析` |
| 健康养生人群 | `主题 + 健康益处/养生方法/科学研究` |
| 泳训家长 | `主题 + 游泳训练/青少年体育/体教融合` |

### 保存规范
保存到 `_knowledge_base/`，文件名格式：`主题-YYYYMMDD.md`

内容必须包含：
- 信息收集时间
- 搜索查询（多个）
- 信息来源URL
- AI 生成摘要
- 关键发现摘要
- 与28度活水馆的关联点
- 下次更新建议

### 核心原则
**搜索验证 > 一切**。AI训练数据有截止时间，涉及最新信息必须搜索确认。

**Tavily 配置状态**: ✅ 已配置。API Key 从环境变量 `TAVILY_API_KEY` 读取（写入 `.env`，已被 `.gitignore` 忽略）。**切勿把 key 明文写进任何 md 或脚本**。

## Step 3: 选题讨论 ⭐ 必做

**不要直接写文章！先讨论选题！**

提供 **3-4个选题方向**，每个包含：

| 要素 | 说明 |
|------|------|
| 标题 | 吸引人的标题（可以有多个备选） |
| 核心角度 | 这篇文章的独特切入点 |
| 目标读者 | 主要面向谁 |
| 工作量评估 | ⭐简单 / ⭐⭐中等 / ⭐⭐⭐需要真实素材 |
| 优势 | 这个角度的优势 |
| 劣势 | 这个角度的风险或不足 |
| 是否需要真实测试/数据 | 是/否 |

每个选题附带**大纲**：
- 3-7个大标题
- 每个标题下的核心内容点
- 预计字数分配

### ⚠️ 然后停下来，等用户选择

不假设用户会选哪个，不自行决定。等用户明确选择后再继续。

## Step 4: 创建协作文档（如需测试/配图）

如果选题需要真实测试数据或特定配图，创建协作文档到 `_协作文档/`。

包含：
- **测试任务清单**：详细步骤、统一Prompt（如需AI辅助测试）、数据记录表格模板
- **配图需求清单**：
  - ✅ 必需配图（列表+描述）
  - ☑️ 可选配图（列表+描述）
- **时间和成本预估**
- **协作检查清单**

目的：让用户清楚知道需要配合什么，AI也清楚要等待什么。

## Step 5: 学习风格

1. **阅读风格指南**：`写作参考/风格指南.md`
2. **阅读历史文章**：本目录 `_published/` 中至少2-3篇文章
3. **提取风格特征**：
   - 开头方式（故事切入/观点直给/场景描写）
   - 结构偏好（小标题式/连续叙述/问答式）
   - 语言特征（口语化程度、常用表达）
   - 金句风格（是否使用、在哪里使用）
4. **Think Aloud**：说明学到的风格特征，确认是否准确

## Step 5.5: 使用个人素材库 ⭐ 降AI味核心

从 `个人素材库/` 搜索与当前主题相关的真实经历、观点、案例。

### 搜索方式
- **方法A（推荐）**：用Grep在原始素材文件中搜索关键词
- **方法B**：查看 `个人素材库/素材索引.md` 中的已整理素材

### 典型使用场景
| 位置 | 用法 | 示例 |
|------|------|------|
| 文章开头 | 用真实经历引入 | "上周带孩子去试课，发现..." |
| 观点支撑 | 用真实评价增强可信度 | "我们有位会员阿姨..." |
| 案例展示 | 用真实项目/会员案例 | 具体的会员故事 |
| 结尾思考 | 用个人洞察升华主题 | CEO的行业思考 |

### 使用原则
- 所有素材**必须真实**，不能编造或夸大
- 素材需要改写成文章逻辑，不能直接复制粘贴
- 标注素材来源（方便用户确认）

## Step 6: 等待用户提供测试数据（如适用）

如果需要真实测试数据或特定配图：
- 等待用户完成测试任务
- 接收数据和配图
- 确认数据完整性
- 然后才开始写作

如果不需要测试数据，跳过此步。

## Step 7: 创作初稿

### 写作核心原则（从历史文章中提取）

**1. "我"视角贯穿全文**
- 全文80%以上从第一人称出发
- 不写"某某认为"，写"我觉得"
- 不写"据了解"，写"我查了一下"、"我在网上看到"

**2. 用真实细节替代一切抽象描述**
- ❌ "投入很大" → ✅ "投了近3000万"
- ❌ "效果不错" → ✅ "30多个孩子拉通比，他考了第二"
- ❌ "时间很长" → ✅ "每周大概14小时，平均每天两小时"
- 每1000字至少2-3个具体数字/场景/品牌名

**3. 辩证思维必须有**
- 讨论任何话题，至少要看到正反两面
- 不做二极管，但最终要亮明自己的态度
- 可以承认"我不确定"，但不能通篇骑墙

**4. 口语化表达**
- 像在跟一个聪明朋友聊天
- 可以用"其实"、"说实话"、"大概率"等语气词
- 适度使用口语（"还挺猛的"、"也没啥"）
- 偶尔可以来一句糙话增强真实感，但点到为止

**⚠️ 口语化检查清单（尤其是从英文视频/论文翻译时必查）**
- [ ] 是否有英文副词/连接词残留：ultimately, unprecedented, emerge, genuinely, conversely, notably, significantly, arguably...
- [ ] 是否有"翻译腔"长句（英文复杂句式直译后的中文长句，需要拆解重组）
- [ ] 是否有英文主语从句结构（"这一点很重要的是..."、"值得注意的是..."、"更重要的是..."）
- [ ] 产品名是否保持英文（ChatGPT、Claude、Midjourney、Runway、Suno等为正常），但普通名词必须翻译

**5. 用类比把复杂事说简单**
- 抽象概念必须找到通俗比喻
- 参考："麻将规则"比喻公平、"华为苹果vs恒大碧桂园"比喻制度差距

**6. 必须有明确态度**
- 每篇文章必须有清晰的个人立场
- ❌ "对于这个问题，每个人可能有不同看法"
- ✅ "我不太愿意他在9岁多的年龄，按照这种方式学习和生活"

**7. 结构：连续叙述，不用小标题**
- 像一场不中断的长谈
- 用逻辑和过渡来引导阅读，而非靠小标题分段
- 从一个具体故事展开 → 层层推进到宏观 → 再回到个人

### 28度活水馆内容要点
写作时可以自然融入的品牌要素（不要全部堆砌，根据文章主题选择性融入）：
- **体医融合**理念（不是普通游泳馆/健身房）
- **分龄分温分级**泳池设计（3个独立教学泳池：33℃/0.7米、32℃/0.8米、30℃/1.0米）
- **8级进阶体系** + 自救技能优先
- **彩虹泳帽**进阶系统和换帽赛
- 中医康养：7个药汤池（专家定制配方）、电磁脉冲池、富氢池
- 综合体一站式体验：康养+游泳+健身+亲子+休闲
- 投资近3000万，面积11000平米，重庆首家
- 50米阳光泳池（国际比赛标准）
- 白色瓷砖（非蓝色，体现水质自信）

### 开头和结尾
- **开头**：从个人真实场景切入（"上周我在..."），或用数据直接开场，或一句话亮明立场。绝不用AI式宏大叙事开头。
- **结尾**：一句点题收束 / 情绪爆发 / 辩证但坚定的态度 / 回到个人。绝不用"综上所述"式总结。

### 初稿要求
- 初稿可以不完美，重点是把内容和态度写出来
- 预留审校优化空间
- 标注不确定的地方（待确认）
- 参考 `写作参考/风格指南.md` 中的详细规则

保存到 `_drafts/`，文件名：`标题-draft-v1.md`

## Step 7.5: 风格转换实验（可选）

此步骤为**实验性质**，不强制执行。适合对初稿风格不太满意、想探索不同表达方式时使用。

AI可以尝试用不同写作者的语言风格重新表达部分段落，例如：
- Keso（冷静克制的科技评论）
- 和菜头（犀利直白的生活观察）
- 梁宁（产品思维+人文洞察）
- PG（Paul Graham，创业哲理散文）

### 核心原则（不可违反）
- **只借鉴语言风格**（句式、节奏、思维方式），不照搬内容
- **禁止使用原话**（不引用别人的金句当自己的）
- **禁止用他人经历**（"我"始终是沫颖逍遥/小朱哥，所有经历都必须是自己的）
- 风格转换后仍需经过Step 8的三遍审校

## Step 8: 三遍审校（降AI味）⭐ 最关键

详细审校规则见 `写作参考/审校checklist.md` 和 `写作参考/AI味词汇黑名单.md`。

### 第一遍：内容审校（逻辑、事实、结构）
- 事实准确？（数据、时间、产品名称）
- 逻辑清晰？（前后无矛盾）
- 结构合理？（无跑题）
- 无编造？（所有案例都真实）

### 第二遍：风格审校（AI味降重）
- 删除AI套话（参考黑名单）
- 拆解AI句式
- 替换书面词汇为口语
- 加入真实细节和个人态度
- 降AI检测率至30%以下
- **英文夹杂检查**：检查是否有未翻译的英文单词/副词（ultimately, unprecedented, emerge, genuinely, conversely, notably, significantly, arguably, crucially等）
- **行话保护**：批量替换英文时必须先保护行业内通用行话，避免误伤：钩子、gou子、ROI、GMV、CPC、CPM、DAU、MAU、LTV、ARPU等

### 第三遍：细节打磨（标点、排版、节奏）
- 句子长度：15-25字为主
- 段落长度：手机屏幕3-5行
- 标点自然
- 节奏变化：快慢结合

### 审校输出
每遍审校完成后输出：
1. 修改了哪些地方（列表）
2. 为什么要改（简要说明）
3. 修改前 vs 修改后的对比

## Step 9: 文章配图 ⭐

1. **分析配图需求**：根据文章内容确定需要的配图（推荐5-8张）
2. **创建图片文件夹**：`images/文章主题/`
3. **获取图片**：
   - 优先：28度活水馆实景照片（需用户提供）
   - 其次：公共领域作品
   - 再次：AI生成
   - 最后：免费图库（Unsplash、Pexels）
4. **在Markdown中插入图片**（使用绝对路径，确保跨工具兼容）
5. **验证图片显示**

### 配图类型建议
- 场馆实景（泳池、汤池、健身房等）
- 教学场景（教练与学员互动）
- 效果展示（会员变化、数据图表）
- 信息图（流程图、对比图）
- 氛围图（家庭欢乐、健康生活）

### 自动化配图（可选增强）

#### 方式1：Tavily 搜索 + 配图联动（推荐）

使用 **tavily-to-illustration** 脚本，从搜索结果提取关键词生成配图提示词：

```bash
# 搜索 + 自动生成配图提示词
node scripts/tavily-to-illustration.js --topic "文章主题" --style sport

# 可选风格: tech/health/family/sport/business
node scripts/tavily-to-illustration.js --topic "AI在体育培训的应用" --style tech
```

**优势**：
- ✅ 配图与搜索内容高度相关
- ✅ 自动提取视觉关键词
- ✅ 生成 4 个配图提示词（封面 + 3 张内容图）
- ✅ 保存到 `illustration_prompts/` 供后续使用

#### 方式2：baoyu-article-illustrator

如需直接生成配图，可调用 **baoyu-article-illustrator** skill：
- 根据文章内容自动分析配图需求
- 生成配图大纲和提示词
- 调用 baoyu-image-gen 批量生成配图
- 自动插入到文章对应位置

**调用方式**：
```bash
# 方式1：使用 OpenClaw skill 命令（推荐）
/baoyu-article-illustrator 文章.md

# 方式2：直接使用当前工作区的本地兼容路径
bun ./skills/baoyu-article-illustrator/scripts/build-batch.ts \
  --outline outline.md \
  --prompts prompts/ \
  --output batch.json

# 然后使用 baoyu-image-gen 批量生成
bun ./skills/baoyu-image-gen/scripts/main.ts --batchfile batch.json
```

**注意**：
- 优先按 skill 名称调用，不要自己猜测旧路径。
- 当前项目已提供 `skills/` 与 `.agents/skills/` 兼容映射，直接使用当前工作区相对路径即可。

## 发布附录 A：封面图生成（可选，不计入 9 步）

调用 **baoyu-cover-image** skill 自动生成封面图：

1. **确定封面风格**：根据文章主题选择（tech/health/family/sport/business）
2. **准备封面文案**：主标题 + 副标题（可选）
3. **执行生成**：

### 调用方式

```bash
# 方式1：使用 OpenClaw skill 命令（推荐）
/baoyu-cover-image 文章.md --quick

# 方式2：指定详细参数
/baoyu-cover-image 文章.md \
  --type conceptual \
  --palette warm \
  --rendering flat-vector \
  --aspect 16:9
```

### 参数说明

| 参数 | 说明 | 可选值 |
|------|------|--------|
| `--type` | 封面类型 | hero, conceptual, typography, metaphor, scene, minimal |
| `--palette` | 配色方案 | warm, elegant, cool, dark, earth, vivid, pastel, mono, retro, duotone |
| `--rendering` | 渲染风格 | flat-vector, hand-drawn, painterly, digital, pixel, chalk, screen-print |
| `--style` | 风格预设（快捷方式） | 见 references/style-presets.md |
| `--text` | 文字层级 | none, title-only, title-subtitle, text-rich |
| `--mood` | 氛围 | subtle, balanced, bold |
| `--aspect` | 比例 | 16:9, 2.35:1, 4:3, 3:2, 1:1, 3:4 |
| `--quick` | 快速模式（跳过确认） | - |

**费用**：约 ¥0.12/张（通义万相 API）

**输出位置**：根据 EXTEND.md 配置，默认保存到 `cover-image/{topic-slug}/cover.png`

## 发布附录 B：排版（可选，不计入 9 步）

将 Markdown 文章转换为公众号排版格式：

### 自动化排版（浏览器自动化）

使用 **editor.huasheng.ai** 进行自动排版：

```bash
node scripts/format-to-wechat.js \
  --input "_drafts/文章-draft-v1.md" \
  --output "_output/formatted.html" \
  --style "简约"
```

### 参数说明

- `--input`: Markdown 文件路径（必填）
- `--output`: 输出 HTML 文件路径（必填）
- `--style`: 排版风格（简约/商务/活泼等，默认 简约）
- `--headless`: 是否使用无头模式（默认 false，显示浏览器）

### 前置依赖

```bash
# 安装 Playwright
npm install playwright
npx playwright install chromium
```

### 手动排版（备选）

如自动化排版不可用：
1. 复制 Markdown 内容
2. 粘贴到 https://editor.huasheng.ai/
3. 选择排版风格
4. 导出 HTML


### 参数说明

| 参数 | 说明 | 可选值 |
