# 活动照片分析与选材规范 V1.0

目标不是“描述照片”，而是从真实照片中找到一条可传播的课程故事。

# 1. 先分类

每张图标记 1–2 个类别：

- ENV：环境/场地
- ARRIVE：集合/签到/装备
- WARMUP：热身
- SKILL：技能教学
- COACH：教练指导
- CHALLENGE：挑战
- PB：成绩/个人纪录
- TEAM：团队协作
- EMOTION：自然情绪
- DETAIL：手、鞋、车轮、泥、水壶、护具等细节
- FINISH：完赛/复盘/合影
- BRAND：旗帜、Logo、服装等品牌画面

---

# 2. 画面优先级

适合封面：
1. 主体清晰；
2. 动作明确；
3. 能看到户外环境；
4. 有自然表情/关系；
5. 品牌元素不过度抢画面；
6. 没有明显安全瑕疵。

适合正文：
- 连续动作；
- 教练手势/示范；
- 队友互动；
- 技能细节；
- 孩子自己整理装备；
- 失败/调整/再试（若素材确实连续支持）。

---

# 3. 不能从照片直接得出的事实

一张照片通常不能证明：
- “第一次”
- “终于”
- “克服恐惧”
- “比上次快”
- “建立了自信”
- “爱上了运动”
- “学会了团队协作”
- “从不敢到敢”

除非用户补充，或者有连续素材/数据明确支持。

可以更稳妥写：
- “他停下来观察了一下路线。”
- “孩子们在队友完成时站在终点等待。”
- “这组照片里能看到教练反复示范刹车与转向。”
- “这一轮的重点不是速度，而是控制。”

最后一句若涉及课程设计，需要用户资料或品牌课程事实支持。

---

# 4. 不做身份推断

不要通过照片推断：
- 姓名
- 年龄（只能粗略写儿童，除非活动年龄范围已知）
- 学校
- 家庭关系
- 性格
- 健康状况
- 情绪原因

不要给孩子随意起假名来制造故事。

如需匿名：
“一个孩子 / 一位小朋友 / 其中一名学员”。

---

# 5. 活动后故事线模板

优先从素材中选择真实存在的线：

### A. 技能线
不会控制
→ 学动作
→ 任务练习
→ 挑战应用
→ 教练复盘

### B. 挑战线
看见任务
→ 尝试
→ 调整
→ 再试
→ 完成/继续挑战

### C. 团队线
个人任务
→ 双人/小组
→ 分工
→ 等待/帮助
→ 一起完成

### D. 户外线
到达自然环境
→ 身体进入状态
→ 使用真实地形
→ 处理变化
→ 收尾复盘

### E. 教练研发线
为什么设计这个环节
→ 现场发现问题
→ 临时调整
→ 孩子反馈
→ 下次迭代

---

# 6. 照片轮播建议

小红书/抖音照片轮播可用：

1. 封面：最强动作 + 8–14 字标题
2. 环境：今天在哪
3. 技能：今天学什么
4. 挑战：最难的一关
5. 教练：怎么教
6. 团队：伙伴之间
7. 细节：汗/泥/轮胎/手
8. 高光：完成瞬间
9. 复盘：今天真正练到什么
10. CTA：下一场/持续记录

照片不足时不要强行凑 10 张。

---

# 7. 安全画面筛查

发布前检查：
- 是否佩戴课程规定的必要护具；
- 是否出现社会道路/车辆混行；
- 是否出现明显危险动作；
- 是否存在教练无法有效看护的画面；
- 是否有姓名牌、电话、学校等敏感信息入镜；
- 是否有其他家长/儿童未经授权清晰入镜。

发现问题：
优先换图；无法换图则裁切/打码；仍不适合则不发布。
