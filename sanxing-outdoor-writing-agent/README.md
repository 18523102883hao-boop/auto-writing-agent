# 三行少年户外课堂 · 自动化写作 Agent

> 版本：V1.0  
> 用途：将「活动基本信息 + 报名海报 + 活动照片/视频信息」自动转换为公众号、小红书、抖音、朋友圈等平台可直接发布的内容。

## 1. 这个 Agent 要解决什么

三行少年不是普通“活动公司”，也不是只教骑行的专项培训。

它的内容传播要长期回答三个问题：

1. **孩子为什么愿意来？** —— 好玩、有伙伴、有挑战、有真实世界。
2. **家长为什么愿意持续付费？** —— 能看见孩子在身体、技能、自主性、韧性、协作等方面的真实变化。
3. **为什么相信三行少年？** —— 教练真的热爱、真的做过、课程有方法、安全有边界、表达不夸张。

因此，本 Agent 的默认写作风格不是“促销文案”，而是：

> **真实成长纪实 × 户外生命力 × 专业克制**

先让人看见真实的人、真实的动作、真实的场景，再解释这背后的课程价值。

## 2. 支持的自动化场景

### 活动前
- 报名海报配文
- 公众号招募推文
- 小红书招募图文
- 抖音预热视频脚本 / 图文轮播文案
- 朋友圈预热文案

### 活动后
- 公众号活动回顾
- 小红书活动复盘/成长记录
- 抖音活动回顾脚本 / 图文轮播文案
- 朋友圈回顾
- 从照片中提炼下一次可复用的“高光素材点”

### 一键全平台
只需说：
- “这是报名海报，生成活动前全平台宣传包。”
- “这是今天活动的照片和基本信息，生成活动后全平台内容。”
- “只要小红书。”
- “把这次活动写得更像真实教练记录，不要像机构广告。”

## 3. 与原 auto-writing-agent 的关系

保留原 Agent 中好用的设计：
- 多平台路由
- Brief / 事实抽取
- 知识库
- 平台差异化写作
- 审校机制
- 图片/素材优先
- 不编造事实

但三行少年版本做了四个关键改造：

### A. 从“需要层层确认”改为“默认自动完成”
只要资料足够，Agent **不要求先选题、再确认、再写作**。  
自动判断活动前/活动后，直接生成成品。

### B. 从“通用营销”改为“儿童户外成长品牌”
内置三行少年的使命、价值观、六大能力、建设性竞争、户外成长护照等品牌知识。

### C. 从“一套稿改四个平台”改为“同一事实，四种原生表达”
公众号、小红书、抖音、朋友圈分别重写，不做机械缩写。

### D. 增加未成年人、户外运动、安全与科学传播闸门
发布前自动检查：
- 未成年人肖像与隐私
- 监护人授权
- 高风险动作与安全提示
- 绝对化广告用语
- 医疗/近视/大脑发育等过度功效承诺
- 不把孩子包装成广告“代言人”

## 4. 推荐部署方式

### 方式 A：WorkBuddy Agent（最简单）
1. 新建 Agent。
2. 将本目录的 **SYSTEM_PROMPT.md** 全文粘贴到 System Prompt。
3. 将 `workbuddy-skill/references/` 下的文件加入知识库。
4. 如支持视觉模型，开启图片理解能力。
5. 保存。

适合：你希望“上传海报/照片 → 直接出稿”。

### 方式 B：WorkBuddy Skill
`workbuddy-skill/` 已按 Skill 目录组织：

```
workbuddy-skill/
├── SKILL.md
├── references/
│   ├── brand-core.md
│   ├── platform-playbook.md
│   ├── workflows.md
│   ├── photo-analysis.md
│   └── safety-gates.md
└── templates/
    ├── activity-brief.md
    └── output-pack.md
```

将 `workbuddy-skill/` 作为一个 Skill 包上传即可。  
如果在支持项目级 Skills 的环境中，也可以复制到对应的 `.workbuddy/skills/` 目录。

### 方式 C：Claude / Codex / OpenClaw / 其他 Agent
- 把 `SYSTEM_PROMPT.md` 作为系统提示词；
- 把 `references/` 作为知识文件；
- 如工具支持 Skill，直接复用 `workbuddy-skill/`；
- 模型最好支持图片理解，否则“照片自动选材”能力会降级为依据用户文字说明写作。

## 5. 最小输入

Agent 不要求你每次填完整表单。

### 最低可用输入：活动前
- 一张报名海报，或
- 活动名称 + 时间 + 地点 + 年龄 + 报名方式

### 最低可用输入：活动后
- 一组活动照片
- 再补一句：“今天是什么活动”

如果关键事实在海报中，Agent 应先从图片中提取，不重复追问。

---

## 6. 推荐的高质量输入

活动结束后，如果你能额外给 3 类信息，内容会明显更好：

1. **一个具体瞬间**：例如某个孩子第一次敢过障碍。
2. **一句现场原话**：孩子/教练/家长真实说过的话。
3. **一个可量化结果**：骑了几公里、完成几轮、PB 提升多少等。

没有这些信息时，Agent 不能编造。

---

## 7. 默认输出

### 活动前全平台包
1. 公众号海报配文
2. 公众号招募推文
3. 小红书：3 个标题 + 正文 + 封面字 + 标签
4. 抖音：标题 + 发布文案 + 30–60 秒脚本/图文轮播方案
5. 朋友圈：机构版 + 教练个人版
6. 发布前风险检查

### 活动后全平台包
1. 公众号活动回顾
2. 小红书活动回顾
3. 抖音回顾脚本/轮播
4. 朋友圈回顾
5. 本次素材中的 5 个后续内容选题
6. 发布前风险检查

---

## 8. 维护原则

每次真实活动结束后，建议把以下信息持续沉淀：
- 哪类标题打开率/互动好
- 家长真实评论
- 孩子最喜欢的环节
- 现场高光语言
- 常见报名顾虑
- 真实课程数据
- 被证明有效/无效的内容角度

Agent 的护城河最终不是 Prompt，而是：

> **真实活动数据 + 长期积累的孩子成长案例 + 教练现场素材 + 品牌方法论。**
