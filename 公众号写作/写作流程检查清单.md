# 公众号写作流程检查清单（强制使用）

> 每次写作前必须逐条核对，不可跳过任何步骤

## 开场白（必须）
- [ ] 说："现在开始执行公众号写作流程，共9步"
- [ ] 读取 `公众号写作/CLAUDE.md`

> 口径：主流程 9 步（Step 1-9，配图为第 9 步）。封面 / 排版 / 发布是**发布附录**，可选，不计入 9 步。

## Step 1: 理解需求 & 保存Brief
- [ ] 明确主题、目标读者、期望长度、核心信息
- [ ] 保存到 `_briefs/项目名-brief.md`
- [ ] Think Aloud说明对需求的理解

## Step 2: 信息搜索与知识管理
- [ ] 涉及新产品/新技术/新政策/新趋势时必须搜索
- [ ] 使用Tavily Search
- [ ] 保存到 `_knowledge_base/主题-YYYYMMDD.md`

## Step 3: 选题讨论 ⭐关键节点，必须等确认
- [ ] 提供3-4个选题方向
- [ ] 每个选题包含：标题、核心角度、目标读者、工作量评估、优势、劣势、大纲
- [ ] **停下来，明确说："请确认选择哪个选题，或提出修改意见"**
- [ ] **等用户回复后再继续**

## Step 4: 创建协作文档（如需测试/配图）
- [ ] 如需真实测试数据，创建 `_协作文档/`
- [ ] 等待用户完成测试

## Step 5: 学习风格 ⭐关键节点，必须等确认
- [ ] 阅读 `写作参考/风格指南.md`
- [ ] 阅读 `_published/` 中至少2-3篇历史文章
- [ ] 提取风格特征并Think Aloud说明
- [ ] **停下来，明确说："请确认风格理解是否准确"**

## Step 6: 等待用户提供测试数据（如适用）
- [ ] 等待用户完成测试任务
- [ ] 确认数据完整性

## Step 7: 创作初稿
- [ ] 严格遵循风格指南：
  - [ ] "我"视角贯穿全文（80%以上）
  - [ ] 用真实细节替代抽象描述
  - [ ] 辩证思维，有明确态度
  - [ ] 口语化表达
  - [ ] **连续叙述，不用小标题**
  - [ ] 用类比把复杂事说简单
- [ ] 保存到 `_drafts/标题-draft-v1.md`

## Step 8: 三遍审校（降AI味）⭐最关键
- [ ] **第一遍：内容审校**（逻辑、事实、结构）
- [ ] **第二遍：风格审校**（删除AI套话、拆解AI句式、替换书面词汇、加入真实细节）
- [ ] **第三遍：细节打磨**（标点、排版、节奏）
- [ ] 每遍输出：修改了哪些地方 + 为什么改 + 修改前后对比

## Step 9: 文章配图
- [ ] 分析配图需求
- [ ] 创建 `images/文章主题/` 文件夹
- [ ] 生成/获取图片
- [ ] 在Markdown中插入图片

## 发布附录 A：封面图生成（可选，不计入 9 步）
- [ ] 调用 `baoyu-cover-image` skill
- [ ] 或使用手动设计

## 发布附录 B：排版（可选，不计入 9 步）
- [ ] 使用 `format-to-wechat.js` 自动化排版
- [ ] 或手动复制到编辑器

## 发布附录 C：发布（可选，不计入 9 步）
- [ ] 手动发布：登录 mp.weixin.qq.com
- [ ] 或自动化发布（需配置）

---

## 风格检查清单（写作时对照）

| 检查项 | 要求 | 自查结果 |
|--------|------|---------|
| "我"视角 | 全文80%以上从第一人称出发 | ☐ |
| 真实细节 | 每1000字至少2-3个具体数字/场景 | ☐ |
| 辩证思维 | 看到正反两面，最终亮明态度 | ☐ |
| 口语化 | 用"其实"、"说实话"等语气词 | ☐ |
| 连续叙述 | **不用小标题**，像长谈 | ☐ |
| 类比 | 抽象概念找到通俗比喻 | ☐ |
| 明确态度 | 有清晰的个人立场 | ☐ |

---

## 关键决策点（必须停下来等确认）

1. **Step 3 选题讨论后** → 等用户选择选题
2. **Step 5 学习风格后** → 等用户确认风格理解
3. **Step 8 审校完成后** → 等用户确认终稿

**如果用户没有明确说"确认"或"继续"，就停下来等待。**

## 违规惩罚

如果跳过步骤或擅自决定：
- 用户有权要求重新开始
- 必须诚恳道歉并重新执行
