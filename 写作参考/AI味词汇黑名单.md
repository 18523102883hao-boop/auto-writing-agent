# AI味词汇黑名单

本文件列出了需要删除或替换的AI腔词汇和句式。审校第二遍时对照检查。

---

## 一、直接删除的词汇/短语

以下内容在文章中出现时，直接删除整句或整段，重新用口语化方式表达：

### 开头类
- 在当今...的时代
- 随着...的发展/兴起/普及
- 在这个...的背景下
- 近年来...引起了广泛关注
- 众所周知
- 不言而喻

### 结尾类
- 综上所述
- 总而言之
- 总的来说（偶尔可用，但不能作为总结的开头）
- 展望未来
- 让我们拭目以待
- 未来可期

### 过渡类
- 值得注意的是
- 值得一提的是
- 不可否认的是
- 毋庸置疑
- 事实上（偶尔可用，但不能频繁出现）
- 显而易见

### 强调类
- 具有重要意义
- 发挥着至关重要的作用
- 不可或缺
- 举足轻重

## 二、需要替换的词汇

| AI腔表达 | 替换为 | 说明 |
|---------|-------|------|
| 显著提升/显著改善 | 具体数字或"好了不少" | 用数据说话 |
| 充分利用 | 用好/用上 | 口语化 |
| 进行操作/进行调整 | 直接用动词（操作→用、调整→改） | 去掉"进行" |
| 一定程度上 | 删除，或给具体程度 | 模糊表达 |
| 在实际使用过程中 | 用下来 / 实际用着 | 简洁 |
| 具备...的能力/功能 | 能.../可以... | 直接说 |
| 提供了...的可能性 | 能让你.../你可以... | 更直接 |
| 旨在 | 想要/为了 | 口语化 |
| 致力于 | 一直在做/专注做 | 口语化 |
| 赋能 | 帮助/让...更好 | 避免流行语 |
| 助力 | 帮 | 简洁 |

## 三、需要拆解的句式

### "不仅...而且..."
- 不仅提升了效率，而且改善了体验
- 效率确实提高了。体验也好了不少。（拆成两句）

### "不是...而是..."连续出现
- 不是简单的游泳馆，而是综合体；不是传统的教学方式，而是科学体系
- 第一句保留，第二句改为其他句式

### "首先...其次...再次...最后..."
- 机械列举
- 用自然过渡词或直接分段

### 排比句超过3组
- 它是...；它是...；它是...；它是...
- 最多保留3组，其余改为其他句式

## 四、增加人味的技巧

### 加入语气词（适度使用，不过多）
- 确实、其实、说实话、老实说
- 挺...的、还不错、真的
- 你想想、你看、说白了

### 加入个人态度
- "我觉得..."、"在我看来..."
- "说实话，这一点让我印象很深"
- "这个数据让我挺意外的"

### 加入具体场景
- "很多家长反映效果好"
- "上周有个学员的妈妈跟我说，孩子现在每周最期待的就是来游泳"

### 加入口语化衔接
- "说到这个..."
- "对了，还有个事..."
- "你可能会问..."
- "但话说回来..."

## 五、28度活水馆专用注意事项

### 品牌名称统一
- 全称：28度活水馆（首次出现用全称）
- 后续可简称：活水馆、我们
- 泳训中心：28度活水馆泳训中心
- 不要写成：28°活水馆（文章中用汉字"度"）

### 避免过度营销腔
- "震惊！这家游泳馆竟然..."
- "家长们都疯了！纷纷报名..."
- 用真实数据和案例说话，让读者自己判断

### 健康功效描述
- 加入"辅助"、"有助于"等限定词
- 不做医疗承诺
- 引用时注明来源
