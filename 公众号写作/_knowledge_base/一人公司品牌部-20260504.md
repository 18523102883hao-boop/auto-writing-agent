# GPT Image 2 研究笔记

> 收集时间：2026-05-04
> 搜索关键词：OpenAI GPT Image 2, ChatGPT image generation 2026

## 核心信息

- **模型名称**：GPT Image 2（`gpt-image-2`）
- **发布日期**：2026-04-21（13天前）
- **定位**：DALL-E 系列的直接继任者，OpenAI 最新图像生成模型

## GPT Image 系列时间线

| 模型 | 发布日期 |

| GPT Image 2 | 2026-04-21 |

## GPT Image 2 关键特性

1. **思维/推理能力**：首个引入推理模型的图像生成模型，可搜索网络、单次提示生成多图、自我检查
2. **超强文字渲染**：TechCrunch 评测称能生成"可在真实餐厅使用、顾客看不出是AI生成的菜单"
3. **非拉丁文字支持**：日语、韩语、印地语、孟加拉语等
4. **单次多图生成**：一个提示生成不同尺寸的营销素材或多格漫画
5. **最高 2K 分辨率输出**
6. **精细细节渲染**：小文字、图标、UI元素、密集构图

## 架构差异

- DALL-E 2/3：扩散模型（从噪声重建）
- GPT Image 系列：**自回归模型**（像大语言模型一样预测图像），这是文字渲染大幅提升的原因

## 市场数据

- GPT Image 1 首周：1.3 亿用户生成 7 亿张图片
- Sam Altman 称 GPU"在融化"

## 已知弱点（GPT Image 1.5，可能延续到 2.0）

- 多人脸渲染困难
- 某些非拉丁文字（中文、阿拉伯文、希伯来文）仍有弱点
- 某些艺术风格退步
- 过度锐化、人体姿势和物体重叠常见错误
