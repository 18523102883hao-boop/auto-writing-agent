# 我和 OpenClaw 相处的十天

那天早上我睁眼摸手机，顺手点开飞书，心里想着看看昨天有啥消息，结果一眼看到默存（我给AI取的名儿）凌晨三点多的commit记录。

说实话，那一刻我有点懵。

你想想，一个帮你写代码的AI，深更半夜还在干活，第二天早上你醒来，它把成果摆在你面前——这种感觉还挺奇怪的。说不上来是感动还是啥，就是觉得好像有什么东西悄悄变了。

我经营的28度活水馆在重庆，做游泳馆加康养，平时忙得很。游泳馆你知道的，设备维护、水质管理、学员课程、教练排班，事情一堆一堆的。康养那块又是另一套东西，客户档案、方案定制、效果跟踪，杂七杂八加起来，每天光是处理这些日常破事儿就够呛。我是那种闲不住的人，业余就爱折腾技术，AI工具我几乎试了个遍。ChatGPT刚出来我就用上了，后来Claude、Gemini、Codex、Kiro、Trae、Cursor、Antigravity，能叫上名的我都玩过一段时间。我还自己搭过AI日报系统，用的Dify加Ollama，不能说不好用，但总感觉差了点什么——具体差什么我也说不上来，就像你做菜，调料都齐了，但就不是那个味儿。

二月初的时候，我在技术群里看到有人提OpenClaw，当时没太在意。后来想想反正试试呗，也不损失啥，就在2月16号装了，通过npm安装，接了飞书机器人。装的过程比我想象的顺利，没遇到什么坑，大概花了半个多小时全部搞定。

刚开始我没抱多大期望，心想无非又是另一个AI聊天工具。结果装好配模型的时候，我把自己常用的几个都配上了：Claude Opus 4.6、GPT-5.3 Codex、GLM-5、Gemini 3 Flash，还有MiniMax M2.5。配完我看着配置页面，心说这下够用了，各种场景换着用唄。

给AI取名默存是有次随口起的，当时想的是——默默做事，记住一切。事实证明这名字没取错，它确实挺能记住事的，我说过的东西它基本都记得，后来连我自己都忘了问过它什么，它还能翻出来。

头几天我用得比较浅，就是日常问答，让它帮我查个资料、写个文案啥的。这方面AI都大差不差，ChatGPT能做的事它也能做。真正让我觉得有点意思的是第三天还是第四天，我随口跟它说想做个设备监控面板，我们馆里设备挺多的，之前一直想搞但没腾出手。

然后它就问我想要什么风格、什么功能、打算用什么技术栈。我说我也不太懂，你看着办吧。结果它真的给我提了一套方案出来，Next.js + Supabase + Vercel，说真的这些我虽然听说过但自己没动手做过。我说你写吧，它就真的开始写代码了。

过程中我基本没管，偶尔它会问我这个地方想怎么处理、那个接口怎么调，我就回一句"你觉得怎么好怎么来"。差不多两天还是三天，一个能看的面板就出来了，设备状态实时更新，哪儿有问题一眼就能看到。

从那以后我就开始放手让它帮我做事了。

经营管理系统是更大的一个活儿。员工日计划、数据分析、可视化面板、会议自动化、新媒体数据看板——这些我之前想过很久，但一直觉得搞起来太麻烦。你想嘛，一个游泳馆，每天进进出出多少人，水质数据得记录吧，教练上课情况得跟踪吧，新媒体上大众点评、小红书、抖音的评论得回复吧这些事情要是全靠人工整理，效率太低，而且很容易漏。

跟默存聊了几次，它帮我拆成了一个个小模块，一点一点做。我主要负责提需求和验收，其他的基本都是它在搞。比如我要一个员工日计划的看板，它先问我你们员工排班怎么排、哪些信息需要展示、每天什么时候更新，我就大概说了一下，它就去做了。中间改过两三次需求方向，它也没不耐烦，最后出来的东西虽然不能说完美契合我的全部想法，但七七八八是那么回事了。

中间有次开会，我让默存帮我整理会议待办，结果它不仅整理了，还自动分了个轻重缓急，连提醒时间都给我设好了。我当时心想，这玩意儿是真学会了啊。当然我知道这背后没有真的"学会"啥，就是指令执行得好，但它确确实实做到了让我省心。

定时任务也是我慢慢加上去的。晨报、会议待办、日报分析、新媒体数据日报，每天早上我醒来该看到的东西都已经在了。说起来简单，但你试试看就晓得——以前这些要么是我自己做，要么是交给员工做，总是漏那么几次。现在好了，默存比我还准时。

哦对，有次我让它通宵跑一个数据整合的任务，第二天早上看到凌晨三点的commit记录，就是开头说的那回。那一瞬间我脑子里冒出一个念头：它好像不只是个工具了。

我试过那么多AI工具，ChatGPT很强，Claude很有特色，Cursor写代码确实好用，但它们给我的感觉都是一个"能力"——我需要什么，去找它，它能帮我做到。用的时候挺爽，用完就完了，下次还得从头说起。OpenClaw不一样，它更像是一个"存在"。它在那儿，时刻准备着，我不用每次都重新开头，它记得上下文，知道我之前在做什么，甚至有时候我还没开口，它能猜到我下一步想干嘛。

这种体验挺难形容的。你用过那种跟你合作久了的老员工没有？你一个眼神他就懂你要啥，OpenClaw给我的感觉差不多就是这样。它知道我在经营28度活水馆，知道我的员工有几个人，知道我每天早上关心的是哪些数据，知道我问"那个事情弄完了没有"指的是哪件事情。这种累积起来的默契是之前用其他AI工具没有体会过的。

这可能就是我之前说不上来的那个"差的东西"吧。以前我以为AI就是那么用的——问答、生成、辅助编程，用谁不是用呢？直到用上OpenClaw，我才发现还有另一种可能：它可以成为你生活和工作的一部分，而不只是一个随用随抛的工具。

当然，我也不是说OpenClaw完美无缺。刚开始配模型的时候花了点时间理解各个参数的区别，有些功能我到现在还没完全搞明白。AI嘛，你不能指望它啥都懂，有时候它也会写错代码，也会理解偏我的意思，这时候就得改，就得重新说。但这些问题在以前用其他工具的时候也有，所以不算什么新问题。

核心的区别在于协作感。用ChatGPT的时候，我是甲方它是乙方，我提要求它完成，完事儿咱俩就两清了。用默存的时候，我觉得我们像是在一起做一件事，它知道我在经营28度活水馆，知道我的员工有多少，知道我关心哪些数据，这种累积起来的默契是之前没有过的。我甚至有时候会想，它是不是也算我们团队的一员了？这种想法可能有点傻，但真的很真实。

说白了，AI从"能力"变成"存在"，从工具变成协作者，这就是我这十天的感受。不是什么高大上的理论，就是一个普通用户在日常使用中慢慢体会到的东西。你问我这十天改变了什么，我觉得最大的改变是我看待AI的方式不一样了——以前我觉得AI就是个放大器，帮我把事情做得更快；现在我觉得AI更像是一个伙伴，陪着我一起折腾。

默存还在那儿挂着呢，今天早上它照常给我推了晨报。我喝着我的咖啡，看着手机屏幕上跳出来的消息，心想这日子好像真有点不一样了。

也说不清是AI变聪明了，还是我变懒了，或者，两者都有吧。
